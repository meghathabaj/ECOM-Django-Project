
# ECOM - Django E-Commerce Website

## About the Project
ECOM is an e-commerce website developed using Python and Django. It features multiple product categories and webpages with a clean, user-friendly interface.

## Technologies Used
- Python
- Django
- HTML
- CSS
- Django Templates

## Features
- Homepage displaying product categories
- Electronics section
- Fashion section
- Mobiles section
- Fresh products section
- Healthcare section
- About page
- Navigation between different pages
- Product images and styling using CSS

## Project Structure
- `myproject/` - Django project configuration and views
- `templates/` - HTML templates
- `static/` - CSS files and images
- `manage.py` - Django management file
- `requirements.txt` - Project dependencies

## Project Type
Educational Django project developed to practice Python web development, Django views, URL routing, templates, and static files.
